\# Refuge Animal — Muni-Chien



Projet de refonte du logiciel Muni-Chien utilisé par Refuge Animal.



\## Objectif



Remplacer l'application Microsoft Access actuelle par une nouvelle application plus moderne et maintenable.



Le projet comprendra notamment :



\- Gestion des propriétaires

\- Gestion des chiens

\- Gestion et renouvellement des licences

\- Gestion des municipalités

\- Gestion des paiements

\- Module de cartes de fidélité

\## État du projet



Phase actuelle :



\- Analyse de l'application Access existante

\- Analyse de la base de données

\- Validation des besoins avec le client

\- Préparation de l'architecture du nouveau logiciel



Le développement de l'application n'a pas encore commencé.
