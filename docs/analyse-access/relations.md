\# Relations de l'ancien Muni-Chien



\## Relations Access déclarées



Aucune relation explicite n'est actuellement visible dans la fenêtre

« Relations » de Microsoft Access.



Les liens entre les tables semblent être gérés principalement par les

champs communs, les requêtes et/ou la logique de l'application.



\## Relations logiques à confirmer



\- Propriétaire.No prop → Chien.NoProp

\- Propriétaire.No prop → Paiement.No de prop

\- Municipalité.No\_municipalité → Propriétaire.Municipalité

\- Municipalité.No\_municipalité → Rue.Municipalité



Ces relations doivent être confirmées lors de l'analyse des requêtes

et de l'application Access.
