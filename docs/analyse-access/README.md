\# Analyse de l'ancien Muni-Chien



Cette section documente le fonctionnement actuel de Muni-Chien basé sur Microsoft Access.



\## Fichiers analysés



\- Muni-Chien Appli.accdb

\- MC\_data 2026.accdb



Les fichiers Access originaux ne sont pas conservés dans GitHub puisqu'ils peuvent contenir des données confidentielles.



\## Objectifs



\- Identifier les tables et les champs existants

\- Comprendre les relations entre les données

\- Identifier les fonctionnalités de l'ancien logiciel

\- Documenter les règles métier

\- Déterminer les données à migrer

\- Préparer la conception du nouveau Muni-Chien
